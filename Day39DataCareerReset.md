Day 39/120 of building in public
I just completed Case Study 1 of Danny Ma's 8 Week SQL Challenge, and here's what working through a real dataset teaches you that tutorials never do.

The case study centred on a restaurant's customer and membership data. Simple setup. But the questions forced me to think like an analyst:

- Which item was purchased most?
- What did customers buy just before becoming members?
- How do you calculate loyalty points when different rules apply to different items?

And each question introduced a new SQL concept

The framework I used for every single question were these:
1. Translate the question to plain English
2. Design the result table before writing any code
3. Map each column to its source table
4. Then write the SQL

This framework saved me each time I felt stuck.

If you're learning data analytics, Danny's 8 Week SQL challenge (Danny Ma) is one of the best free resources available.
